# 🐾 PetHub - Online Pet Shop Management System(PetSphere AI)

A Full Stack Java Web Application for managing an online pet shop. Built using JSP, Servlets, JDBC, MySQL, Bootstrap and deployed on Railway Cloud Platform.

## 🚀 Live Demo

🌐 Live Website: https://pethub-production-18ed.up.railway.app

## 📌 Project Overview

PetHub is an online pet shop management system where users can browse pet products, manage carts and wishlists, place orders, and submit reviews. The system also provides an admin panel for product and order management.

## ✨ Features

### User Module
- User Registration & Login
- Browse Pet Products
- Product Categories
- Add to Cart
- Wishlist Management
- Place Orders
- Product Reviews
- Contact Support

### Admin Module
- Product Management
- Order Management
